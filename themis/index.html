Themis

A 7-stage control pipeline for multi-drone swarm racing: perception → local track model → path planner → formation → swarm → safety → autopilot. Developed in simulation, then deployed on a custom 250mm quad (Raspberry Pi 5 + PX4) chasing a physical track model.
